# EDO CRM - Система електронного документообігу

Система управління документами для організації електронного документообігу. Веб-додаток на базі React та TypeScript з сучасним UI на основі Mantine.

## Особливості

-  **Автентифікація** - Форма входу та реєстрації з валідацією
-  **Управління документами** - Робота з різними типами документів:
  - Зовнішні документи
  - Вхідні документи
  - Вихідні документи
  - Внутрішні документи
-  **Таблиці документів** - Зручне відображення з можливістю скачування
-  **Сучасний UI** - Адаптивний дизайн з використанням Mantine UI
-  **Error Boundary** - Обробка помилок з користувацьким інтерфейсом
-  **Навігація** - Бічна панель з можливістю згортання
-  **Адаптивність** - Підтримка різних розмірів екранів

## 🛠 Технології

### Основні залежності

- **React 19.1.1** - Бібліотека для створення користувацьких інтерфейсів
- **TypeScript 5.8.3** - Типізована надбудова над JavaScript
- **React Router DOM 7.9.3** - Маршрутизація для односторінкових додатків
- **Mantine 8.3.2** - Бібліотека UI компонентів
- **React Hook Form 7.63.0** - Управління формами
- **Vite 7.1.7** - Інструмент збірки та розробки

### Інструменти розробки

- **ESLint** - Лінтер для перевірки коду
- **TypeScript ESLint** - Перевірка типів TypeScript

## Встановлення

### Вимоги

- Node.js версії 18 або вище
- npm або yarn

### Кроки встановлення

1. Клонуйте репозиторій:
```bash
git clone <repository-url>
cd Edo-crm
```

2. Встановіть залежності:
```bash
npm install
```

## Запуск проекту

### Режим розробки

Запустіть сервер розробки:
```bash
npm run dev
```

Додаток буде доступний за адресою `http://localhost:3000`

### Збірка для продакшену

Створіть оптимізовану збірку:
```bash
npm run build
```

### Попередній перегляд продакшен збірки

Після збірки перегляньте результат:
```bash
npm run preview
```

## Основні компоненти

### AppRouter
Головний роутер додатку, який визначає всі маршрути та обгортає додаток в необхідні провайдери (MantineProvider, ErrorBoundary).

### Sidebar
Бічна панель навігації з можливістю згортання. Містить посилання на всі основні розділи додатку.

### AuthForm
Компонент форми авторизації та реєстрації з валідацією полів та перемиканням між режимами входу та реєстрації.

### ErrorBoundary
Компонент для перехоплення та обробки помилок рендерингу. Відображає зрозумілий інтерфейс при виникненні помилок.

### NotFound
Сторінка 404 для неіснуючих маршрутів з можливістю повернення на головну сторінку.

### Таблиці документів
Компоненти для відображення різних типів документів:
- `ExternalTable` - Зовнішні документи
- `IncomingTable` - Вхідні документи
- `OutgoingTable` - Вихідні документи
- `InternalTable` - Внутрішні документи
- `HelpTable` - Тарифи

## 🗺 Маршрутизація

Додаток використовує React Router для навігації:

- `/` - Головна сторінка (форма авторизації)
- `/external` - Зовнішні документи
- `/incoming` - Вхідні документи
- `/outgoing` - Вихідні документи
- `/internal` - Внутрішні документи
- `/help` - Тарифи
- `/*` - Сторінка 404 для неіснуючих маршрутів
