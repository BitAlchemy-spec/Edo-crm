# Система електронного документообігу (ЕДО)

## Опис проекту

Система електронного документообігу - це додаток, розроблений для управління документами в організації. Система дозволяє автоматизувати процеси створення, обробки, зберігання та архівування документів.

## Основні функції

- Управління зовнішніми документами
- Обробка вхідних та вихідних документів
- Робота з внутрішніми документами
- Архівування документів
- Створення та використання шаблонів
- Управління контактами контрагентів
- Налаштування компанії
- Управління тарифами
