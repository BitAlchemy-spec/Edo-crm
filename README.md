# Система електронного документообігу

Система управління документами для організації 

## Особливості

-  **Автентифікація** - Форма входу та реєстрації з валідацією
-  **Управління документами** - Робота з різними типами документів:
  - Зовнішні документи
  - Вхідні документи
  - Вихідні документи
  - Внутрішні документи
-  **Таблиці документів** - Зручне відображення з можливістю скачування
-  **Сучасний UI** - Адаптивний дизайн з використанням Mantine UI
-  **Error Boundary** - Обробка помилок з користувацьким інтерфейсом
-  **Навігація** - Бічна панель з можливістю згортання
-  **Адаптивність** - Підтримка різних розмірів екранів
