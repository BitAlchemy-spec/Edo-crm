# Система електронного документообігу

## Опис проекту

Система електронного документообігу - це додаток, розроблений для управління документами в організації

## Основні функції

- Управління зовнішніми документами
- Обробка вхідних та вихідних документів
- Робота з внутрішніми документами
- Архівування документів
- Створення та використання шаблонів
- Управління контактами контрагентів
- Налаштування компанії
- Управління тарифами
